# ✨ Happy Birthday Jaya - Special Birthday Surprise Website ✨

An enchanting, emotional, and interactive digital birthday celebration website created especially for **Jaya** ❤️.

---

## 🌟 Overview & Features

- **❤️ Hero / Opening Screen**: Full-screen romantic greeting with portrait aura, animated particles, floating hearts, and "Open Your Birthday Surprise" button.
- **💖 Photo Reveal**: Emotional quote card dedicated to Jaya with glowing borders and floating stickers.
- **💌 Heartfelt Birthday Message**: Premium glassmorphism letter with realistic line-by-line typewriter animation and replay control.
- **📸 Polaroid Photo Gallery**: 9 customizable photo cards with playful tilts, heart reaction counters, hover zooms, and captions.
- **🌸 Why You're Special**: 6 animated glass cards celebrating Jaya's beauty, kindness, positive energy, and presence.
- **🎂 Birthday Wishes Timeline**: 7 scroll-revealed blessings and prayers.
- **🕯️ Interactive Make-a-Wish Cake**: 3D styled birthday cake with clickable animated candle flame, realistic smoke puff, multi-layer confetti burst, fireworks, and wish sent banner.
- **📸 Memory Wall & Lightbox**: Interactive masonry memory grid with fullscreen Lightbox viewer (Next, Previous, Keyboard arrows, Heart reaction).
- **🔐 Secret Surprise Modal**: Glowing locked button opening a secret letter with romantic backdrop vignette.
- **👑 Grand Centerpiece & Final Message**: Grand portrait with rotating petals, sparkles, and blessings.
- **🎉 Final Surprise Extravaganza**: "One Last Surprise" celebratory confetti & fireworks explosion.
- **🎵 Music Player**: Floating audio toggle (`Play Music` / `Mute Music`) with equalizer bars, support for `assets/birthday-song.mp3`, and automatic Web Audio synthesizer fallback.

## 📸 How to Replace Jaya's Photos

1. Navigate to the `assets/images/` folder.
2. Replace `jaya1.jpg` through `jaya9.jpg` with your own photos of Jaya, keeping the same filenames:
   - `jaya1.jpg` — Hero section portrait
   - `jaya2.jpg` — Photo reveal section
   - `jaya3.jpg` to `jaya8.jpg` — Polaroid gallery & Memory wall photos
   - `jaya9.jpg` — Final grand centerpiece photo
3. Refresh the page in your browser — all photos will update immediately!

---

## 🎵 How to Replace the Birthday Song

1. Place your desired song file in the `assets/` folder and name it `birthday-song.mp3`.
2. The player will automatically load and stream the new song when the user clicks **🎵 Play Music**.

---

## 🚀 How to Run

Simply double-click `index.html` to open it in any web browser, or serve it using any local HTTP server (such as VS Code Live Server or `npx serve .`).
